# Createx Online School — Landing Page

Учебный лендинг онлайн-школы (направления: маркетинг, менеджмент, HR, дизайн и разработка). Проект сделан с упором на интерактивность и чистый фронтенд.

## 🛠 Что реализовано в проекте:
* **Адаптивная верстка:** аккуратный дизайн всех секций (Header, About, Directions, Certificate, Questions) с выдержанными стилями.
* **Фильтрация карточек (List):** интерактивное переключение направлений по категориям с плавной анимацией.
* **Детализация (Detail):** просмотр подробной информации о курсах через динамическое раскрытие или модальные окна (с данными, подгружаемыми из JSON).
* **Валидация форм:** проверка пользовательского ввода с помощью регулярных выражений (RegEx).
* **Scroll Reveal:** плавное появление блоков и карточек контента при прокрутке страницы вниз.
* **Hover-эффекты:** интерактивный отклик интерфейса при наведении курсора на кнопки, ссылки и карточки.
* **CRUD система** возможность добавлять карточки с курсами (CREATE), изменять(UPDATE) и удалять(DELETE).

## 🚀 Используемые технологии:
* HTML5 / CSS3
* JavaScript (ES6+, Fetch API, DOM manipulation)
* Git & GitHub Pages
